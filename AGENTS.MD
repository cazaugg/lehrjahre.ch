# Agents Instructions

Languages:

- Frontend: German
- Everything else: English

## General

- Security is key don't make security decisions without explicit user consent.
- Simplicity is key. Ask before expanding scope even when in building mode
- Backend: Make sure api is robust and easy to use.
- Frontend: Make design elements reusable with CSS (for small elements) and vue components for more complex elements. Consistency is key.
- Database: Don't add additional tables/columns if you can avoid - keep it simple. Always ask user before add ing new tables/columns.
- Keep documentation short and concise. Skip obvious things and explain design choices. Add short instructions on how to use things.

## Deployment

- This will be deployed behind a reverse proxy and a web application firewall.
